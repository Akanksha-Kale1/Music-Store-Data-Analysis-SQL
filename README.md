🎵 Music Store SQL Analysis

Project Overview-

This project focuses on analyzing a digital music store database using PostgreSQL.
The main goal of the project is to use SQL queries to understand customer behavior, sales, invoices, music preferences, artists, and tracks.
I used different SQL concepts to answer business-related questions and generate useful insights from the database.

Tools & Technologies-
PostgreSQL
SQL
pgAdmin
GitHub

Database Tables

The project contains multiple tables related to the music store, including:
Customer
Invoice
Invoice Line
Track
Album
Artist
Genre
Employee
Playlist
These tables are connected using relationships between primary keys and foreign keys.

Key Insights

The analysis was used to identify:
Senior employees in the organization
Countries with the highest number of invoices
Highest-value invoices
Cities generating the highest revenue
Customers with the highest spending
Customers interested in Rock music
Top Rock artists based on number of tracks
Tracks longer than the average track length
Customer spending on the best-selling artist

Project Objective
The objective of this project was to practice SQL using a real-world style database and understand how SQL can be used to answer business questions and extract meaningful information from data.
